# 🏋️ Fitness Assistant (AI Powered)

Modern arayüzlü, yapay zeka destekli bir fitness ve beslenme asistanı uygulaması.  
Tkinter tabanlı arayüz + NLP destekli cevap sistemi.
Antrenman ve beslenme için ayrı ayrı arayüzlere gerek kalmadan tek bir arayüz ile etkileşim.
---

##  Özellikler

- 🎯 Fitness Chat
- 🥗 Nutrition Chat 
- 🤖 Dil çevirisi (Girdiler Türkçe, backend'de Türkçe -->  İngilizce --> Türkçe)
- 🌙 Modern Dark UI



## 🛠️ Kullanılan Teknolojiler

- Python
- Tkinter
- OLLAMA - TİNYLLAMA
  (Uygulamanın çalıştırılabilmesi için dil modelinin kurulumunun yapılması gerekmektedir.)
